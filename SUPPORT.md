# Support

- **Bug / critical gap in an existing feature** → [open an Issue](https://github.com/PinWright/pinwright-ue-support/issues/new?template=bug_report.yml)
- **Plugin will not install, load, or run on your engine** → [open a compatibility report](https://github.com/PinWright/pinwright-ue-support/issues/new?template=compatibility_report.yml)
- **New / extra feature idea** → [Discussions → Ideas](https://github.com/PinWright/pinwright-ue-support/discussions/new?category=ideas)
- **Install / usage question** → [Discussions → Q&A](https://github.com/PinWright/pinwright-ue-support/discussions/categories/q-a)

Supported engines: **Unreal Engine 5.3 – 5.8, Windows only.**

## Response times

Issues and Discussions usually get a first response within two business days. That is a target rather
than a guarantee — replies can take longer around holidays and engine releases. A first response is
not always a fix; it may be a question, a workaround, or a note that the report is queued.

This repository is the only support channel. The plugin source is not here.
