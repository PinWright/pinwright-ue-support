## What changed

- **The plugin is open source (MIT).** The full source is at
  [PinWright/pinwright-ue](https://github.com/PinWright/pinwright-ue): clone it into your project's
  `Plugins/PinWright` folder and build it, free. See that repository's README for the build steps.
- **Support moved.** Report bugs and compatibility problems in
  [Issues](https://github.com/PinWright/pinwright-ue/issues); ask questions and propose features in
  [Discussions](https://github.com/PinWright/pinwright-ue/discussions). Nothing here is monitored any
  more, and this repository cannot accept new issues.
- **The Fab listing is unchanged.** It stays the paid convenience install: a prebuilt binary per
  engine version, no build step. Same plugin, same updates.
- **The demo edition is gone.** It was a capped build of an otherwise closed-source plugin, and MIT
  source makes it pointless. Its release has been deleted; build from source or use Fab instead.

Old issues and discussions here stay readable for reference.
