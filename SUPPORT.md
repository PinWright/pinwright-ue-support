# Support — moved

**This repository is archived.** PinWright is open source under the MIT License at
**[github.com/PinWright/pinwright-ue](https://github.com/PinWright/pinwright-ue)**, and all support
happens there.

- **Bug / critical gap in an existing feature** → [open an Issue](https://github.com/PinWright/pinwright-ue/issues/new)
- **Plugin will not install, load, or run on your engine** → [open an Issue](https://github.com/PinWright/pinwright-ue/issues/new)
- **New / extra feature idea** → [Discussions](https://github.com/PinWright/pinwright-ue/discussions)
- **Install / usage question** → [Discussions](https://github.com/PinWright/pinwright-ue/discussions)

## Response times

Issues and Discussions usually get a first response within two business days. That is a target rather
than a guarantee — replies can take longer around holidays and engine releases. A first response is
not always a fix; it may be a question, a workaround, or a note that the report is queued.

Nothing filed in this repository is monitored any more, and it cannot accept new issues.
